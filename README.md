# 巨信 Cheat 前端

这是巨信 Cheat 的 Vue 3 + Vite 前端源代码。公开仓库只包含前端界面，不包含服务端、数据库、风控规则、部署脚本、密钥或客户端签名材料。

## 开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

前端默认把 `/api` 和 `/socket.io` 代理到本机 `3000` 端口；生产环境由反向代理转发到服务端。

## 说明

- 服务端接口、数据库结构和风控逻辑不在本仓库公开。
- 生产环境的 `.env`、数据库连接、邮件授权码、门禁哈希、管理员密码和签名文件均未上传。
